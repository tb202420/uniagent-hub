## 2. 复现命令

```powershell
# 1) 安装依赖（运行时 + 测试）
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt

# 2) 全量测试（一条命令，退出码 0 = 全绿）
.\.venv\Scripts\python.exe -m pytest -q

# 3) 生成 JUnit + 覆盖率证据（本报告的数据来源）
.\.venv\Scripts\python.exe -m pytest -q `
  --junitxml=data/pytest-v30.xml `
  --cov=core --cov=adapters --cov=agent --cov=web `
  --cov-report=term --cov-report=json:data/coverage-v30.json
```

> 环境提示：PATH 上的 `python` 在本机是坏 shim（`python -c` 会静默失败），
> 一律使用 `.venv\Scripts\python.exe` 全路径；CI 使用 `python-version: 3.12/3.14` 矩阵。

## 6. 诚实边界（写材料时必须保留）

1. 覆盖率是**行覆盖率**，不是分支覆盖率；不能表述为"代码正确性 72%"。
2. 交互终端在 **Windows 是持久管道会话，不是 PTY**；`test_terminal_session`
   会在 Windows 走 pipe、在 POSIX 走 `pty`，两者都断言字节流与 Guard 行为。
3. 真机 HIL 数字（152ms / 100ms / 5.1s）来自 2026-10-24 的
   `real_device_e2e_20261024` 证据，本次 v3.0 测试**未重新测真机**，不得把
   SIL 的 100–141ms 写成 152ms。
4. Tauri 桌面壳状态仍为"已编译验证"，本次未做 NSIS 打包与窗口运行实测。
