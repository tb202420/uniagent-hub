UniAgent Hub v3.0 审批分支演示实测（2026-11-07）
环境：Windows 11 · Python 3.14.3 · SIL 模拟器（非真机）· 每次前执行 demo/reset.ps1

【分支一：拒绝】
命令：python -m demo.irrigation_approval --decision rejected
结果：exit=0 · 11.1s
关键输出：
  [demo] Agent 结果: ok=False · [error 1999] 工作流部分步骤失败: s3(control_pump):[error 1003] HITL 审批未通过（rejected），调用已阻止
  [demo] 分支判定: decision=rejected branch_ok=True
  [demo] control_pump 审计: {"guard_result": "blocked", "error_code": 1003, "args": {"action": "on", "duration": 300}}
  [demo] 审计链: ok · 审批记录 1 条
说明：工具未执行；审批拒绝写入审计，错误码复用 1003（不新增错误码）。

【分支二：改成 60 秒】
命令：python -m demo.irrigation_approval --decision modify
结果：exit=0 · 10.9s
关键输出：
  [demo] Agent 结果: ok=True
  [demo] 分支判定: decision=modify branch_ok=True
  [demo] control_pump 审计: {"guard_result": "passed", "error_code": 0, "args": {"action": "on", "duration": 60}}
  [demo] 审计链: ok · 审批记录 1 条
说明：审批注入的 duration=60 重新经过参数校验后生效；审计记录为实际执行的 60 秒，
      而不是原始请求的 300 秒，证明"审计记录的是真正执行的参数"。

【分支成功判定】
脚本不是"退出码 0 就算成功"，而是按分支检查：
- rejected：Agent 必须失败，control_pump 审计必须 blocked/1003；
- modify：Agent 必须成功，control_pump 审计参数必须 duration=60；
- approved：Agent 必须成功，control_pump 审计必须 passed。
任一条件不满足，脚本返回 1。
