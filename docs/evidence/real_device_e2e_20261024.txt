  传感器状态：本轮测试时 DHT22 / BH1750 / 土壤探头未接线（读数段落如实标注）

[3] Hub 全链路（真机 → MQTT → Hub → Guard → 执行器 → 回执 → 审计）

      control_pump 全部来自真机（retain 注册自动发现，平台侧零配置）

      isError=false，返回设备回执帧（pump=on, request_id=real-hub-1 与调用
      trace_id 一致），端到端 latency_ms=100
    - tools/call get_soil_moisture：isError=false，0ms（状态缓存路径）
    - 审计落盘（data/realdev_e2e_audit.jsonl）：
